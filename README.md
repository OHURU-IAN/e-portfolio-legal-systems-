# e-Portfolio — RBFC 7213 Legal Systems & Social Political Thoughts

A single-page e-portfolio built for the university course **RBFC 7213: Legal Systems & Social Political Thoughts**. It records the course purpose, learning outcomes (LO1–LO4), key concepts, a Supreme Court class trip and a final reflection.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=fff)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=fff)

## Structure

```
index.html      Portfolio content, organised into sections
css/style.css   Layout and styling
img/            Photos from the course
```

## Sections

About Me · Course Purpose · Learning Outcomes · My Learning Journey · Supreme Court Class Trip · Key Concepts · Applying the Course to Life, Career & Society · Final Reflection

## Run locally

Open `index.html` in a browser. It has no dependencies or build step.
